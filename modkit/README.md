# ForgeLoader Dev Kit KR214

Crie com `python modkit/krmodkit.py new autor.nome --name "Meu mod" --output MeusMods/autor.nome`, edite `Scripts/main.lua`, valide e empacote:

```powershell
python modkit/krmodkit.py validate MeusMods
python modkit/krmodkit.py pack MeusMods/autor.nome --output Pacotes/autor.nome.flmod
```

Instale o `.flmod` pelo ForgeLoader e reinicie. Consulte [API](../docs/MOD-API.md), [desenvolvimento](../docs/DEVELOPMENT.md) e [estado](../docs/STATUS.md). Os exemplos executáveis ficam em `examples/forgeloader` e `examples/native/forge_native`; os exemplos UE4SS antigos exigem portabilidade.
